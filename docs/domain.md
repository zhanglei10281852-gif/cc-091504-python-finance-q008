# 领域说明

股票挂钩票据由标的篮子、观察日、障碍水平、票息与到期交付规则构成。停牌、
节假日顺延、公司行动和行情更正会改变观察证据。现金流一旦支付便成为独立
账务事实，后续修订通过差额调整反映，而不是删除原记录。

`reference/domain.json` 保存可公开的示例枚举与精度约定。正式业务记录使用
稳定标识，并区分业务发生时间（观察日、行情所属日）、系统接收时间
（published_at / recorded_at）与记录版本（version）。

## 关键模型

- **条款版本（TermsVersion）**：条款按 `effective_from` 版本化。每个观察固定
  其观察日生效的条款版本；篮子成分变更、障碍调整等发行人修订以新版本进入，
  只影响生效日及之后的观察。
- **行情（PriceRecord）**：同一（标的，交易日）可有多版。`provisional` 临时价
  只能让观察待确认；`official` 官方价才能确认观察；`revoked` 撤销某版官方价
  （经 `corrects` 指向），权威选择自动回退；更正以更高版本官方价经 `corrects`
  取代旧版。权威行情按知识时间（published_at ≤ 当前时钟）选取。
- **观察（Observation）**：逐日敲入观察与预定观察日（票息/敲出/到期）两类。
  状态：`scheduled → pending → confirmed`，或 `cancelled`（敲出/到期后）。
  缺价、临时价、行情被撤销都会使观察停留在 `pending`，绝不跳过。
  证据快照含价格版本、调整后初始价、各级障碍位、比率与公司行动路径。
- **现金流（Cashflow）**：`projected → confirmed → paid`；已付款项被更正后
  标记 `adjusted`，差额由独立的 `adjustment` 现金流承接（可独立结算）；
  不再应付的未付款项 `cancelled` 但保留历史。票息含记忆特性：未付期间
  累计 backlog，下一满足条件的期间一并补付。
- **结算（Settlement）**：以 `instruction_id` 幂等。仅 `confirmed` 且到达
  付款日的现金流可结算；同一指令重试返回原结果。
- **公司行动（CorporateAction）**：拆分等以因子调整初始价（观察日 ≤ 除权日
  才适用），调整路径写入证据。

## 重算语义

任何行情/条款/公司行动事件进入后全量重算：观察与现金流按签名比对，
只有变化才追加新版本。已付现金流的观察依据被撤销时先标记
`under_review`，不产生调整；依据重新确认后再按差额调整。
